# 浏览器验收清单

目标：本地滚动式调试台在桌面 1440×900 和手机 390×844 可操作，首屏看到任务入口与执行按钮。

| 用户功能/状态 | 检查方式 | 预期证据 |
| --- | --- | --- |
| 自然语言导航 | 输入指令，点击执行，查看结果 | 正确坐标、通过状态、真实轨迹 |
| 信息补充 | 只指定机器人，再补充坐标 | 提问后不移动，续接后执行 |
| 刷新恢复 | 澄清状态和完成任务分别刷新 | 计划、历史与目标不丢失 |
| 新任务/例子 | 新任务、单机/双机示例按钮 | 清除旧续接关系，填入例子 |
| 仅诊断不修复 | 取消勾选，注入故障，执行 | diagnosed，无修复事件 |
| 手动规则/AI 模式 | 切换两种模式，注入故障后诊断 | 修复前失败、修复后通过明确区分 |
| 两机器人选择/重置/仅导航 | 点击卡片、下拉选择、重置、导航 | 正确机器人执行动作 |
| 取消 | 任务运行中点击取消 | canceled，按钮消失，锁释放 |
| 历史/证据/导出 | 选旧任务、展开事件、下载 JSON | 显示对应任务，文件含完整证据 |
| 越界与空输入 | 非法坐标、全空白输入 | 不执行，提示明确 |
| 布局与滚动 | 桌面/手机截图、横向溢出检查 | 无裁切、遮挡或重叠；长证据可读 |
